# 🕸️ LangGraph Python Agent

A simple, stateful AI agent built in Python using **[LangGraph](https://github.com)**. This project uses graphs to manage agent memory, states, and loops.

## 🚀 Features
* **State Management:** Easily tracks conversation history and variables across steps.
* **Cyclic Workflows:** Allows the agent to loop back and self-correct or call tools multiple times.
* **Clean & Modular:** Separate files for tools, graph logic, and execution.
